Um sistema de login de usuários bem simples.

Front end pelo ChatGPT utilizando HTML, CSS e JS;

Back end por mim, utilizando Java, Spring boot, Maven e PostgreSQL.

Ainda pretendo melhorar e diminuir a cachorrada que ficou. No mais, está até que funcionando bem.


<h3>Para ver o código funcionando:</h3>

<ol>
 Copie o projeto para o seu dispositivo.
<li>git clone https://github.com/GustavoV138/login-register-springboot.git</li>
<li>Abra o projeto em um editor de sua preferência. (Recomendo o IntelliJ)</li>
 (É necessário ter o JDK instalado em seu computador)
<li>Execute a classe 'LoginRegisterFullstackSpringbootApplication'</li>
<li>Com o projeto em execução, no navegador, insira a URL "localhost:8080/"</li>
</ol>
